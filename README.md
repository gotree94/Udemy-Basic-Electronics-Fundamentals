## 7. 학습 로드맵 (추천 순서)

```
[기초 물성]
   에너지원/반도체 → PN 접합 다이오드 → VI 특성 → 동적저항/온도
        ↓
[다이오드 응용]
   정류(반파/전파/브리지) → 필터(C/L/π/T) → 클리퍼 → 클램퍼
        ↓
[특수 다이오드]
   Zener(안정화) → LED → Photo → Tunnel → Varactor → Solar Cell
        ↓
[BJT DC 분석]
   구조/영역 → α·β·γ → CB/CE/CC → 부하선·Q점 → 바이어스 4종 → 스위치
        ↓
[BJT AC 분석]
   커플링캡 → AC 부하선 → hybrid 파라미터 → re 모델 → π 모델 → CE 앰프 → Darlington
        ↓
[FET]
   FET vs BJT → JFET 구조/특성/전이특성/전압제어저항 → 파라미터
        ↓
[MOSFET]
   구조/영역 → IV 특성 → 채널길이변조 → Small-signal → gm/rd → Body Effect → IC 기술
        ↓
[실습]
   Multisim: 계측기 → 다이오드 → 정류기 → 논리게이트 → 클리퍼 → BJT → FET
```
